# Khitanan Kaka Bilal
Template undangan digital premium, static HTML/CSS/JS.

1. Buka `index.html` untuk preview.
2. Tambahkan musik sendiri di `assets/music/backmusic.mp3`.
3. Ganti nomor WhatsApp pada `js/script.js`:
   `whatsapp:"6280000000000"`
4. Bisa di-deploy gratis menggunakan GitHub Pages.

Foto asli Kaka Bilal sudah ditempatkan di `assets/images/kaka-bilal.webp`.
